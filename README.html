01它能做什么

打开它，桌面上会有一个课程表窗口和一个可以拖动的小圆球。它主要帮你做六件事：

看课表

周一到周五、每天 7 节课一目了然。临时调课点一下就能改，改完会记住。

提醒上课

每节课前 4 分钟自动弹出大屏倒计时，前 2 分钟提醒“预备铃响了”，上课时自动消失。

记学生积分

按小组或个人加分、扣分，能随机点名、看统计图、查历史记录，还能导出 Excel。

记卫生扣分

卫生扣分单独统计，不影响学生积分；每天中午自动归档并重新开始。

手机查看

手机和电脑连同一个 Wi-Fi 时走局域网直连；不在同一网络时开启云同步，也能每 8 秒看到最新课表、积分和卫生。

身份分开，密钥不怕丢

教师端 / 学生端 / 值日生端 / 只读查看四种入口，各用各的密钥；忘记密钥要在手机 App 上点「同意」才能重置。

放心用班级数据默认只保存在这台电脑上。开启云同步后，数据会先用 AES-256-GCM 加密，再上传到你指定的 Gitee 仓库；手机凭访问令牌读取，只能查看和确认密钥重置，不能修改课表和积分。

02第一次使用

  1. 打开程序 双击桌面上的「课程表」图标，或者在开始菜单里找到它。第一次打开时，Windows 可能会询问是否允许运行，选择「允许」即可。
  2. 选择身份 程序会先弹出「请选择进入的身份」：教师端、学生端、值日生端、查看信息。登录方式见第 3 节。
  3. 看到主界面 进入教师端后，左边是本周课表，右边是实时状态和常用按钮。能看到这些，就说明已经正常启动了。
  4. 记住初始密钥 教师端初始密钥是 710；学生端默认密钥是自己的学号；值日生密钥由老师生成后告知。建议教师第一次登录后在「课程设置 → 密钥管理」里改掉默认密钥。
  5. 确认开机自启 主界面右下角会显示「已设置开机自启」。如果不是这个提示，点它打开设置，在「开机自启」里点一下「注册开机自启」。这样每次开机后提醒功能才会自动工作。
注意上课提醒依赖后台服务。如果只打开主界面、没有开机自启，倒计时不会自动弹出。可以重启一次电脑，或在任务管理器里确认有 ClassSchedule_Backend.exe 正在运行。

03四种身份与登录

打开程序后先选身份，不同身份能看到的界面和数据范围不一样。登录窗口都可以自由缩放，默认就是最大化，不会再出现显示不全的情况。

身份登录需要进入后能做什么
教师端教师密钥，初始 710完整功能：课表、积分、卫生、课程设置、调试工具、局域网服务
学生端选班级和自己，密钥默认是学号只读门户：我的积分、我的记录、班级排行、荣誉榜、今日课程与倒计时，还能自定义头像和昵称
值日生端学号 + 姓名 + 职务 + 专用密钥值日长进入积分管理，卫生长进入卫生管理，只能操作自己负责的部分
查看信息不需要密钥课程表、积分、卫生三块只读内容
教师端不用反复输密钥进入教师端以后，修改科目、打分、卫生管理、调课、禁用时间段等操作都不会再要一次密钥； 只有「重置密钥」这一步需要重新确认。

学生端怎么登录

  1. 选班级下拉框里选自己的班级。
  2. 选自己在「我是谁」里选「学号 姓名」。
  3. 输入学生密钥第一次使用直接填自己的学号；改过之后就用新密钥。

值日生怎么登录

  1. 选学号和姓名姓名会自动带出，用来核对身份。
  2. 选职务只有被老师任命过的同学才有职务可选；没有职务时「进入」按钮是灰的，无法登录。
  3. 输入专用密钥由老师在主界面「值日生任命」里生成，生成时会显示密钥，可一键复制发给学生。

忘记密钥：必须手机确认

教师密钥、学生密钥、值日生密钥都支持自助重置，但不能只凭手机号直接重置，需要手机端同意：

  1. 点登录窗口左下角的「忘记密钥」填写教师绑定的手机号和新密钥（要输两遍）。
  2. 电脑上显示「等待手机确认…」这时请求已经发到手机，等待时间最长 120 秒。
  3. 在手机 App 里点「同意」手机弹出「电脑端请求确认」对话框，点同意后电脑上的新密钥立即生效；点拒绝则保持原密钥不变。
手机必须先连上手机和电脑要在同一个 Wi-Fi，且手机 App 已连接（详见附录）。 手机不在线时，电脑只会提示「无法发起手机确认」，不会直接重置密钥。
为什么这一步必须有手机知道手机号的人不少，但手机在老师手里。加上这一步，别人拿到手机号也没法把密钥改成自己的。

05上课提醒怎么工作

你不需要按任何按钮。程序会在每节课开始前自动做三件事：

上课前 4 分钟自动弹出大屏倒计时，显示距离预备铃还剩多久。
→
上课前 2 分钟进入预备铃阶段，提示回座位、关闭电子设备。
→
正式上课倒计时窗口自动关闭，不打扰上课。

注意倒计时窗口可以按 Esc 或点右上角关闭，但上课提醒还会继续。 如果窗口被误关，后台会在几秒内重新打开它。

06桌面悬浮球

屏幕上那个圆形的小球，是快速打开积分和卫生的入口。它可以一直浮在所有窗口上面。

怎么操作

操作效果
按住拖动把球挪到屏幕任意位置，下次打开还在原处
单击打开「学生积分」
右键弹出菜单：换皮肤、打开积分、只读查看、隐藏悬浮球
右键 → 换皮肤深蓝、翡翠、紫夜三种内置配色，另有插件提供的「默认头像」和「自定义皮肤」，共五种可选

找不回来？球被隐藏后，点主界面的「更多功能 → 显示悬浮球」，它就会重新出现。 如果还是找不到，确认电脑上没有把它拖到屏幕边缘之外。

07学生积分

点主界面的「学生积分」或单击悬浮球即可打开（教师端内不再要密钥）。窗口默认按小组显示，也可以切换成按学生显示。值日长从「值日生端」进入时打开的是同一个窗口。

给小组或个人打分

  1. 选人按小组视图时直接点「评价打分」，会先让你选一个小组；按学生视图时，先点卡片选中学生（可多选，也可以用「全选」「反选」）。
  2. 勾选本次涉及的学生打分窗口里会列出这个范围内的学生，默认全选。只给其中几个人记分，就把其他人的勾去掉。
  3. 选理由、填分值先选分类（常用、课堂表现、日常纪律、卫生劳动、文明礼仪、学业任务），再选具体理由。分值填正数是加分，负数就是扣分，例如 3 或 -2。
  4. 确定点确定后立刻记入，卡片上的分数会马上更新。自己输入的新理由会自动保存，下次可以直接选。
说明积分记在每位学生名下，小组分数由组员分数自动汇总。所以给小组打分，实际是给组里每个被勾选的同学记一笔。

随机点名

点底部的「随机点名」，卡片会快速滚动，最后停在一名同学上，并弹出他的积分情况。适合课堂提问、抽人回答问题。

08卫生管理

卫生扣分是单独记录的，不会算进学生积分。点「卫生管理」即可打开（教师端内不再要密钥）；卫生长从「值日生端」进入时打开的也是这里。

记录一次卫生扣分

  1. 点「记录扣分」在窗口右下角。如果提示还没有小组，请先去学生积分里建好小组。
  2. 选小组和学生先选是哪个小组，再在名单里点选这次涉及的同学（按住 Ctrl 可以多选）。
  3. 填写理由和分值理由可以从常用项里选，也可以自己输入。分值填扣多少分，例如 2。
  4. 提交提交后小组累计扣分会立刻更新，同时记下操作人（教师或卫生长姓名）和精确到秒的时间。

窗口里其他按钮

按钮作用
扣分明细查看当前班级的所有卫生扣分记录，每条都带时间与记录人
撤销记录选中一条误记的扣分撤销，小组累计扣分立即还原（不可恢复）
小组扣分图用条形图比较各小组的扣分多少
理由分布用饼图看哪类卫生问题出现得最多
每笔都可追溯教师端和卫生长记录的每一条卫生扣分都会保存记录人； 在扣分明细、小组详情和撤销窗口里都能看到「谁在什么时候记的」，误记时可直接撤销。
每天的报告每天第一次打开程序时，会自动弹出一份卫生扣分报告。 周一上午还会同时显示上周的小组积分，方便在班会上总结。

09课程设置

点主界面的「课程设置」，会看到一个有四个标签页的窗口：

标签页能做什么
开机自启注册或取消开机自启，查看当前自启状态和启动命令
禁用时间段设置一段时间内暂停所有提醒，例如期中考试、运动会
临时调课把某天某节课换成别的科目，或恢复成默认课表
密钥管理查看当前密钥状态、修改教师密钥、绑定/保存教师手机号（忘记密钥时用它发起手机确认）

设置禁用时间段

在「禁用时间段」里填写开始时间、结束时间和备注（例如「期中考试」），点添加即可。这段时间内不会弹出倒计时； 重叠的时间段会自动合并。考试结束后，记得回来删掉它，提醒就会恢复正常。

临时调课

在「临时调课」里选择星期和节次，填入新科目并保存；也可以直接在左侧课表上左键点格子来调课。 调课只影响显示和提醒，不会改动默认课表。想恢复默认，在调课记录里删除即可。

值日生任命

主界面右侧点「值日生任命」，选择学生和职务（值日长 / 卫生长），类型会自动对应「积分 / 卫生」。 专用密钥留空会自动生成 6 位数字；添加成功后会弹出密钥窗口，可以一键复制发给学生。 需要换人时，先在列表里选中旧任命点「撤销任命」，再添加新的。

修改教师密钥

  1. 打开「课程设置 → 密钥管理」窗口会显示当前是默认密钥还是已自定义。
  2. 输入旧密钥、新密钥、确认新密钥旧密钥默认是 710。新密钥不能和旧密钥相同。
  3. 点保存看到「密钥已更新」就成功了，下次登录教师端用新密钥。
忘记密钥怎么办在登录窗口点「忘记密钥」，填绑定的教师手机号和新密钥， 再在手机 App 上点同意即可重置（见第 3 节）。不要再靠删除 password.json 来绕过： 该文件运行时被后台进程锁定，删不掉；即使删了也只会恢复成默认的 710。

10自动归档与重置

为了每周、每天都能从零开始统计，程序会在固定时间自动存档并清空当前记录。全过程不需要你操作。

时间会发生什么
每天中午 12:00卫生扣分先写入《卫生记录.xlsx》，然后清零，开始新一天的记录
每周一中午 12:00学生积分先写入《积分记录.xlsx》，然后清零，开始新一周的记录
每天第一次打开程序弹出卫生扣分日报；周一上午同时展示上周小组积分
归档在哪里两个 Excel 文件就在程序所在文件夹里。每次归档会新增一页明细， 另外有一页「total」保存历史累计总分，可以一直往下对照。
别误会积分“清零”只是新一轮统计开始，历史记录都在 Excel 和操作日志里，并没有丢失。 如果你不希望重置，请在中午 12:00 前先手动点「本周数据归档」把数据存下来。

换电脑或重装系统

把整个程序文件夹复制到新电脑即可，名单、积分、密钥、值日生任命都会一起带过去。建议每个月把整个文件夹复制一份到 U 盘或网盘作为备份。

升级不会丢数据安装新版本时，已经存在的名单和积分不会被覆盖； 只有第一次安装、文件夹里还没有这些文件时，才会写入一份空白名单。

12常见问题

上课前没有弹出倒计时，怎么办？
按顺序检查四件事：
1）当天是不是周六、周日；
2）是不是设置了「禁用时间段」（课程设置里可以看到）；
3）后台服务有没有在运行——打开任务管理器，找 ClassSchedule_Backend.exe；
4）电脑时间是否准确。
如果后台服务没运行，重启一次电脑，或确认「开机自启」已注册。也可以点「更多功能 → 测试倒计时窗口」先确认窗口本身正常。
悬浮球不见了
可能是被右键菜单里的「隐藏悬浮球」收起来了。点主界面「更多功能 → 显示悬浮球」就能叫回来。
忘记密钥了
教师端默认密钥是 710；学生端默认是自己的学号。如果已经改过又忘了，在登录窗口点「忘记密钥」： 填教师绑定的手机号和新密钥，然后在手机 App 上点「同意」即可重置（120 秒内有效）。 手机不在线时无法重置，请先让手机连上电脑（见附录）。
点了「忘记密钥」，手机没有弹确认框
按顺序检查：
1）电脑上的局域网服务是否在运行（「更多功能 → 局域网连接」会显示状态）；
2）手机是否和电脑在同一个 Wi-Fi，手机 App 是否显示“已连接”；
3）教师端「课程设置 → 密钥管理」里绑定的手机号，是不是你填的那个；
4）请求只有 120 秒有效期，超时后重新点一次「忘记密钥」。
手机确实连不上时，电脑只会提示“无法发起手机确认”，不会直接重置。
登录窗口太小 / 按钮显示不全
登录相关窗口现在都可以自由缩放，并且默认最大化打开。如果还是觉得挤，直接拖窗口边缘拉大即可； 高分屏下窗口和文字会按系统缩放比例自动放大。
积分 / 卫生突然变成 0 了，是丢了吗？
大概率是到了自动重置时间：卫生每天中午 12:00、积分每周一中午 12:00。重置前的数据已经写进 《积分记录.xlsx》和《卫生记录.xlsx》，打开 Excel 就能看到。也可以在「更多功能 → 查看操作日志」里确认。
升级后名单和积分还在吗？
在。安装包不会覆盖已有的学生、小组和积分文件，只会更新程序本身。但为了保险，升级前把整个文件夹复制一份仍是好习惯。
双击图标没反应 / 提示文件被占用
通常是有旧进程还在运行。按 Ctrl+Shift+Esc 打开任务管理器，结束名称以 ClassSchedule 开头的进程，再重新打开。 安装或升级时安装程序也会自动帮你结束这些进程。
界面字太小或有点模糊
程序会跟随 Windows 的缩放比例自动放大。如果仍然觉得小，可以在 Windows「设置 → 显示 → 缩放」里调大比例，然后重新打开程序。
用调试工具改过系统时间，怎么恢复？
正常关闭主界面时，程序会自动把时间恢复成北京时间。如果没恢复成功，在「更多功能 → 调试工具」里点「恢复北京时间」， 或手动在 Windows 设置里打开「自动设置时间」。
倒计时窗口能不能换个位置或大小？
可以把鼠标放到窗口边缘拖动大小，也可以拖动标题栏移动位置。窗口不会被锁定在屏幕中央。
手机 App 一直显示「连接失败」或「未连接」？
按顺序检查：手机和电脑是否连在同一个 Wi-Fi；电脑上「局域网连接」是否显示「服务运行中」； 手机里填的地址是否和电脑上显示的完全一致（电脑重启后地址可能变化）； Windows 防火墙是否允许了程序访问专用网络。校园网互相隔离时，可以改成手机开热点、电脑连热点。
手机上的数据和电脑不一样？
正常情况下几秒内就会自动同步。如果一直不更新，先把手机 Wi-Fi 断开再连上，或退出 App 重新打开； 也可以点一下右上角状态，重新填写电脑地址再连接。

14自动更新

程序会自己检查新版本，不用手动换文件。开机自启的后台服务每 6 小时访问一次 Gitee 仓库，发现新版本就在后台下载好； 主程序启动或运行中检测到下载完成，会安静地替换并自动重启，通常只会看到窗口闪一下。

数据不会丢更新只替换程序代码（app/*.py）或整体覆盖安装， 不会动名单、积分、卫生记录、roles.json、password.json 这些数据文件。
首次需要手动装一次2.0.0 及更早版本没有更新模块，需要手动安装 2.1.0； 从 2.1.0 开始才会自动检查并升级到后续版本。

补丁还是完整安装包？

你的情况下发内容说明
当前版本正好是上一版，且这次只是小改动renew 增量补丁只包含改动的几个文件，几十 KB 到几百 KB，几秒完成
跨了多个版本、没提供补丁，或 exe 也有更新setup 完整安装包静默安装并自动重启，稍慢但最稳妥
本次改动很大（例如 UI 重构）只提供 setup维护者会跳过 renew，避免补丁不可靠

更新失败怎么办

  1. 会弹出「自动更新失败」窗口点「重试」会重新下载；点「取消」会用浏览器打开发布页。
  2. 手动下载安装包下载最新的 ClassSchedule_Setup_x.y.z.exe，直接安装覆盖，数据不受影响。
  3. 更新后版本没变可能是清单里 sha256 还没填好，或当前版本与补丁不匹配；重新安装最新完整包即可。

发布新版本（维护者）

  1. 升版本号改 version.py 后运行 python build_exe.py，生成新的 dist/ 与 version.json。
  2. 生成补丁（小改动才做）python make_renew.py --old 上一版目录/version.json， 输出 dist/renew_旧版本_to_新版本.zip 并打印 sha256；改动超过约 60% 时会提示不建议发布补丁。
  3. 上传发行版附件用 Inno Setup 编译 setup.iss，把安装包（和可选的 renew zip）传到 Gitee Release。
  4. 更新清单编辑 update/latest.json：填版本、下载地址、sha256；不发布补丁时 "renew": null。 不填 sha256 客户端不会下载，可先留着占位。
  5. 推送生效提交并推送 update/latest.json 后，已安装用户会在 6 小时内收到更新。
测试建议先在测试机装上一版，把 update/latest.json 指到测试地址（settings.json 的 update_manifest 可覆盖）， 走一遍「检查 → 下载 → 应用 → 重启」，确认版本与数据都正常后再正式发布。

附用手机查看（局域网）

不用数据线，也不用连接互联网。只要手机和电脑连的是同一个 Wi-Fi（或同一个手机热点）， 就能在手机上看课表、当前课节、小组积分和卫生扣分，而且是实时更新的。

电脑课程表正在运行，负责提供数据
⇄
同一个 Wi-Fi手机和电脑在同一个网络里
⇄
手机用 App 查看，并可确认密钥重置

第一次连接：先在电脑上取地址

  1. 确认程序在运行 电脑上的课程表正常打开，并且后台服务已启动（一般设置了开机自启就会自动运行）。
  2. 打开「更多功能 → 局域网连接（手机）」 窗口里会显示「服务运行中」，下面有一串类似 http://192.168.1.23:8765 的地址。
  3. 点「复制地址」 如果 Windows 弹出防火墙提示，选择「允许访问」。这一步只需要做一次。

然后在手机上连接

  1. 连上同一个 Wi-Fi 注意不要一个用 Wi-Fi、一个用流量。校园网如果会隔离设备，可以改成手机开热点、电脑连热点。
  2. 打开 App，点右上角「未连接」 把刚才复制的地址粘贴进去，点「连接」。只填 IP 也可以，程序会自动补上端口。
  3. 看到「已连接 · 七年级10班」 课表、积分、卫生三个页面显示的就是电脑上的真实数据。地址会被记住，下次打开自动连接。

还没装 App？把老师发来的安装包（app-debug.apk）传到手机，点开安装即可（系统可能会提示“允许安装未知应用”，同意一次就行）。 注意：直接用手机浏览器打开这个地址只会看到接口说明页，看不到课表、积分和卫生，请使用 App 查看。

手机上能看到什么本周课表、正在上的课（绿色高亮）、当前状态、小组积分与明细、卫生扣分统计和图表。 手机端不能改课表和积分，只有一个例外：电脑发起的密钥重置，需要你在手机上点「同意」。

手机确认密钥重置

电脑端在登录窗口点「忘记密钥」并提交后，手机 App 会自动弹出「电脑端请求确认」对话框：

  1. 看清楚内容对话框里会写明是重置教师密钥、学生密钥还是值日生密钥。
  2. 点「同意」或「拒绝」同意后电脑上的新密钥立即生效；拒绝则什么都不变。
  3. 没看到弹窗？确认手机 App 处于连接状态；请求只保留 120 秒，超时就在电脑上重新发起一次。

“实时”是什么效果

电脑上打分、记卫生、调课，或者到了上课、下课、预备铃的时间，手机会在几秒内自动更新，不需要下拉刷新。 手机锁屏或切换网络后，App 会自动重连。

手机连不上怎么办

  • 先确认手机和电脑连的是同一个 Wi-Fi，而不是一个用 Wi-Fi、一个用流量。
  • 电脑上的「局域网连接」窗口要显示「服务运行中」；没有就点一下「启动服务」。
  • 第一次运行如果防火墙提示点了「取消」，需要到 Windows 防火墙里允许程序访问专用网络。
  • 有些校园网会隔离设备，手机和电脑互相访问不了。可以让手机开热点，电脑连这个热点。
  • 电脑重启后局域网地址可能变化，重新打开「局域网连接」窗口，把新地址填到手机里。
使用范围手机查看是只读的，不需要密码，但仅限同一个局域网使用；只有密钥重置需要你在手机上确认。 请不要把地址发到公网，也不要在不可信的公共 Wi-Fi 上开启。如果不需要手机查看，关掉后台服务即可。
