值日生使用手册

这份说明只讲值日生每天会用到的操作：怎么登录、值日长怎么记积分、卫生长怎么记卫生扣分， 以及忘记密钥、误操作时该怎么办。看不懂的地方可以直接翻到最后的「常见问题」。

适用版本 2.1.0 适用系统 Windows 10 / 11 值日长 积分管理 卫生长 卫生管理 数据 提交即保存

1你是哪种值日生

值日生端按「职务」分流，两种职务进入的窗口不一样。

值日长

进入「学生积分」

给个人加分或扣分，查看小组积分、积分明细和统计图表。扣分、加分都会立即记到学生名下。

卫生长

进入「卫生管理」

只记录卫生扣分，按小组汇总、按理由统计。卫生扣分单独计算，不会计入学生积分。

可以同时担任两个职务 如果你既是值日长又是卫生长，登录时在「职务」下拉框里选择这次要做的事， 进入对应窗口即可；做完退出，再登录一次即可切换。

2登录值日生端

全程鼠标点选，不需要输入账号。

  1. 打开桌面上的「课程表」等身份选择窗口出现。
  2. 点击「值日生端」卡片图标是一把扫帚，说明文字为「按职务进入积分 / 卫生管理」。
  3. 选择自己的「学号 姓名」下拉列表里按班级列出所有学生。选中后，姓名会显示在下方。
  4. 确认「职务」系统会自动列出你被任命的职务，例如「值日长 · 积分管理」。
  5. 输入专用密钥任命时老师给你的 6 位数字，输入时显示为圆点。
  6. 点击「进入」验证通过后直接打开对应窗口。
「进入」按钮是灰色的？ 说明这个学号还没有被任命为值日生。下拉框里会显示「暂无值日生任命」， 请联系老师先在「教师端 → 值日生任命」里添加你的职务。
密钥只属于你 专用密钥相当于你的操作密码，不要告诉同学，也不要写在黑板或课桌上。 老师那边也只保存加密结果，无法查看明文，只能帮你重置。

3忘记密钥怎么办

不用找老师改文件，登录窗口里可以直接自助重置，但需要老师手机确认。

  1. 在登录窗口点左下角「忘记密钥」先选好你的学号和职务。
  2. 输入教师绑定的手机号就是老师平时用来接收确认消息的号码。
  3. 设置新密钥建议用 6 位数字，设置后请记住。
  4. 等老师在手机 App 上点「同意」手机弹出确认框，老师确认后新密钥立即生效。
如果提示「教师尚未绑定手机号」 这时无法自助重置，请直接找老师，由老师在教师端重新设置你的值日生密钥。

4值日长：积分管理

登录后看到的是「学生积分」窗口，所有加减分都在这里完成。

4.1 认识界面

位置内容用途
顶部左侧班级下拉框、人数默认就是本班；一般不需要切换
顶部右侧「按小组」/「按学生」切换卡片的排列方式
中间学生卡片 / 小组卡片显示姓名、学号、当前积分；点击可选中
底部左侧全选、反选一次选中多名学生
底部右侧随机点名、评价打分、更多功能常用操作入口
积分怎么算 积分记在每位学生个人名下；小组积分等于本组所有组员的积分之和， 所以给个人加减分后，小组数字会自动变化。

4.2 给一名或几名学生打分

  1. 先选学生「按学生」视图下，点击一张或多张学生卡片，选中的卡片会变蓝。
  2. 点击「评价打分」弹出评价窗口，顶部会列出本次要打分的学生。
  3. 勾选本次涉及的学生默认全部勾选；只想给其中几人记分时，点一下取消其他人的勾选。
  4. 选择「分类」常用、课堂表现、日常纪律、卫生劳动、文明礼仪、学业任务。
  5. 选择或输入「理由」可直接输入新理由，提交后会自动保存，下次能直接选。
  6. 填写「分值」正数是加分，负数是扣分，例如 3 表示加 3 分，-2 表示扣 2 分；不能填 0。
  7. 点击「提交」窗口关闭，卡片上的积分立即更新，底部状态栏会显示本次结果。
分值超过 10 会二次确认 这是防止多输一个 0。看到「分值 +30 超过 10，确定提交？」时， 先确认是不是自己填错了，再决定是否继续。

4.3 按小组打分

  • 切换到「按小组」，每张卡片就是一个小组成员集合。
  • 点击小组卡片上的「为本组学生打分」，会直接带着全组学生进入评价窗口。
  • 也可以先选中小组卡片，再点底部的「评价打分」。
  • 小组卡片上显示的是本组积分合计，点开还能看组员明细。

4.4 全选与随机点名

  • 全选 / 反选：适合全班统一加分，或先全选再取消少部分人。
  • 随机点名：点底部「随机点名」，卡片会滚动后定格一名学生。 这个功能只负责点名，不会自动加减分；需要记分时再走「评价打分」。

4.5 记错了怎么更正

要做的事入口说明
撤回刚才的记录更多功能 → 撤回积分记录选中记录后撤回，积分会同步还原
查某个学生的历史更多功能 → 查询积分明细可按学生查看每一笔加分 / 扣分
看本周统计更多功能 → 周度积分统计图按小组展示本周积分变化
看理由分布更多功能 → 理由分布饼图了解加分、扣分主要集中在哪些理由
看小组对比更多功能 → 小组加减分对比图横向比较各组表现
提醒低分学生更多功能 → 低积分预警列出积分偏低的学生
核对操作历史更多功能 → 查看操作日志每次打分都有时间、学生、理由和余额
这几项先问老师再用 「新增学生」「批量导入学生」「删除选中学生」「编辑学生资料」「小组管理」「手动修改积分」「本周数据归档」 属于名单和数据维护，不是日常记分操作。拿不准时不要点，避免误删或改动全班的积分。
提交后不用另存 每次提交都会立即写入数据文件，也会同步给同一局域网内的手机端； 直接关闭窗口不会丢失已经提交的记录。

5卫生长：卫生管理

卫生窗口只处理卫生扣分，和学生积分完全分开。

5.1 认识界面

  • 顶部：班级下拉框、本班累计扣分。
  • 中间：小组列表，每行显示小组名、记录条数、累计扣分。
  • 点击任意小组行，可以查看组员扣分明细和每一条扣分记录。
  • 底部：记录扣分、扣分明细、小组扣分图、理由分布。

5.2 记录卫生扣分

  1. 点击「记录扣分」打开记录窗口。
  2. 选择小组选好后，学生列表会自动列出该组组员，并默认全部选中。
  3. 选择学生只扣其中几人时，按住 Ctrl 逐个点选，或按住 Shift 连选。
  4. 填写理由可从预设理由中选择，也可以直接输入新理由；新理由会保存为下次的预设。
  5. 填写扣分必须是大于 0 的整数，默认是 1。
  6. 点击「提交」窗口关闭，小组累计扣分立即更新，底部会显示本次扣分结果。
扣分记到个人，小组自动累计 每条扣分都会记在具体学生名下；小组列表里的数字是本组组员扣分的合计。 因此点开小组能看到「谁因为什么扣了几分」。
每条记录都有记录人和时间 提交时会自动记下操作人（例如「卫生长 张三」或「教师」）和精确到秒的时间。 之后在「扣分明细」、小组详情和撤销窗口里都能看到，老师也能核对是谁在什么时候记的。
卫生扣分不进积分 卫生管理里的扣分不会改变学生积分，也不会出现在积分统计图里。 两边各算各的，避免重复扣分。

5.3 查看与统计

  • 扣分明细：按时间倒序列出本班所有卫生记录，包含时间、小组、学生、分值、理由和记录人。
  • 小组扣分图：用柱状图比较各组累计扣分，扣分多的组排在前面。
  • 理由分布：用饼图看扣分主要集中在哪些理由，方便班会总结。
  • 组员明细：直接点小组行，查看该组每名成员的扣分和逐条记录。

5.4 撤销记错的记录

卫生记录也支持撤销，入口在卫生管理窗口底部的「撤销记录」。

  1. 点击「撤销记录」只读模式或没有记录时不会显示可用列表。
  2. 在列表里找到要撤销的那一条每行按「时间 | 小组 | 学生 | 分值 | 理由 | 记录人」排列，最新的在最前面。
  3. 点「撤销选中记录」也可以直接双击这一行。
  4. 确认撤销弹窗会再次显示记录人、时间和分值，确认后该条记录被删除，小组累计扣分立即还原。
撤销不可恢复 撤销是把这条记录从数据里删除，不能撤销「撤销」操作。 删除前请核对时间、学生和分值，确认确实是记错的那一条。
老师也能看到每一笔 教师在教师端打开卫生管理时，同样可以查看扣分明细和记录人， 并使用同一个撤销工具处理误记。记录人信息不会因为撤销其他记录而改变。

6手机端查看

手机端不是必须的，值日生用电脑端就能完成全部记录。

  • 手机和电脑连同一个 Wi-Fi / 局域网，打开 App 即可查看课表、积分和卫生。
  • 手机上的数据来自电脑端，电脑端提交后稍等片刻即可看到最新结果。
  • 重置值日生密钥时，老师需要在手机 App 弹出的确认框里点「同意」。
手机看不到数据？ 先确认手机和电脑在同一个网络、电脑端后台服务正在运行； 仍然看不到时找老师检查局域网连接。

7值日生守则

  1. 密钥保密：不借给同学，不公开写在教室可见的位置。
  2. 离开就退出：记完分关闭窗口，避免别人用你的身份操作。
  3. 先核对再提交：看清学号、姓名、分值和正负号，再点提交。
  4. 只做分内事：名单、小组、手动改分、数据归档按老师安排操作。
  5. 有疑问先问：拿不准该加几分、该不该扣，先问老师或班干部。
  6. 不删他人记录：发现记录有问题，先报告老师，再按老师要求撤回。

8常见问题

「进入」按钮是灰色的，点不了

说明当前学号没有被任命为值日生，或者「职务」下拉框是空的。

解决：换回自己的学号，确认姓名下方出现职务；仍然为空就找老师在教师端任命。

提示「专用密钥不正确」

先确认选的是自己的学号和职务，再检查数字有没有输错。

确实想不起来时，点「忘记密钥」按第 3 节自助重置；教师没绑手机号就找老师重置。

卫生管理里提示「当前班级还没有小组」

卫生扣分需要先有小组和组员。请老师或值日长在「学生积分 → 更多功能 → 小组管理」里分好组。

打分窗口里学生列表是空的

通常是所选小组还没有成员，或者当前班级还没有学生。

先在「按学生」视图确认班里有学生，再检查小组是否分配了组员。

填了分值，提交却没有反应

检查三点：至少勾选一名学生、理由不能为空、分值必须是整数且不能为 0。

窗口里会用红字提示具体原因。

不小心提交错了怎么办

值日长：在「更多功能 → 撤回积分记录」里找到这一笔并撤回。

卫生长：在卫生管理窗口点「撤销记录」，选中记错的那一条撤销即可； 弹窗会显示时间、学生、分值和记录人，确认后再删除。

关掉窗口后数据会丢吗

不会。每次点「提交」就已经写入数据文件，关闭窗口不影响已提交的记录。

可以同时打开积分和卫生两个窗口吗

值日生端一次只进入一个职务对应的窗口。需要切换时，关闭当前窗口， 重新选择「值日生端」并选另一个职务登录即可。
